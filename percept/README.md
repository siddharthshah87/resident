# percept — perception daemon

Makes the owner's activity on this NUC legible to the resident agent, with consent,
a kill switch and an audit trail. Stdlib Python, no sudo, runs as a `systemctl --user` unit.

## What it records (only on change, polled every 5 s)

| kind | source on this box | fields |
|---|---|---|
| `window` | X11: `xprop -root _NET_ACTIVE_WINDOW` → `xprop -id … WM_CLASS _NET_WM_NAME` | `app`, `title` |
| `idle` | `org.gnome.Mutter.IdleMonitor.GetIdletime` (gdbus) + `org.gnome.ScreenSaver.GetActive` | `state` ∈ active / idle (≥5 min) / locked |
| `system` | `journalctl -o json --after-cursor` (system journal, user is in `adm`) | `event` ∈ failed-unit / oom / usb / network / login / crash, `summary`, `detail` |

GNOME Wayland path exists too: `org.gnome.Shell.Introspect.GetWindows`, falling back to
a `ps`-based list of running GUI apps (no titles). On this machine the session is X11.

Record format: `{"ts": iso, "kind": "window"|"idle"|"system", "app", "title", "summary", ...}`
in `activity.jsonl`. Entries older than 24 h are pruned on every write.

## Privacy by construction

Titles and app names only. No screenshots, keystrokes, clipboard, or URLs beyond what a
title shows. Titles matching `(?i)password|passcode|2fa|otp|bank|login` become `[redacted]`.
Nothing is recorded while the screen is locked.

## Commands

```
percept status     # ON/OFF, service state, session type, idle, current window, entries last hour
percept off        # kill switch: creates percept/DISABLED; daemon idles, records nothing
percept on         # remove kill switch
percept summary    # (re)write activity.md (≤1500 chars) and print it
percept once       # single poll, print new entries + summary (debug)
journalctl --user -u percept.service -f
tail -f ~/agentos/percept/activity.jsonl
```

`activity.md` is regenerated by the daemon every 60 s: current state (since when), last 60 min
grouped by app with minutes and 3 most recent titles, system events in 24 h (max 10), policy line.
The coordinator includes it into `machine.md`.

## Event bus

`failed-unit` and `oom` events are also dropped into `~/agentos/inbox/<epoch>-system.json`
as `{"ts","kind":"system","summary","detail"}` for the resident agent.

## Service

`~/.config/systemd/user/percept.service` (Restart=always), enabled via the intent system
(consent intent recorded with `intent add`, unit enabled through `intent apply`, service
attributed with `intent adopt`). Disable: `systemctl --user disable --now percept.service`.
